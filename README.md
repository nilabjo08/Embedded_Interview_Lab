# 🚀 C & Embedded Interview Lab

**A practical, beginner-friendly interview preparation platform for aspiring Embedded Software and Firmware Engineers.**

Preparing for your first embedded engineering interview? This project is designed to help freshers and engineers with **0–1 years of experience** strengthen their C programming and embedded systems fundamentals through structured learning and practical exercises.

## 🎯 Project Objective

The goal of this project is to make entry-level embedded interview preparation more accessible, organised and practical.

Instead of studying disconnected topics, learners can explore important concepts, practise coding problems, test their knowledge and prepare for technical interviews in one place.

## 📚 Topics Covered

- **C Programming:** Variables, data types, arrays, strings, functions and structures.
- **Pointers & Memory:** Pointer arithmetic, double pointers, memory concepts and storage classes.
- **Embedded C:** Bit manipulation, bitwise operators, registers and `volatile`.
- **Microcontrollers:** STM32 fundamentals, GPIO, ADC, PWM and interrupts.
- **Communication Protocols:** UART, SPI, I2C and CAN.
- **RTOS Fundamentals:** Tasks, scheduling, queues, semaphores and mutexes.
- **Debugging & Testing:** Firmware troubleshooting, validation and practical scenarios.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the HTML file in your browser.
3. Navigate through the chapters and learning sections.
4. Practise coding exercises and quizzes.
5. Use the roadmap to organise your preparation.

No complicated installation is required.
